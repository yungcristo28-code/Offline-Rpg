# Igor Offline RPG — versão para GitHub Actions

Protótipo de RPG Android offline com o personagem Igor, um anjo vampírico com dano em área e recuperação de HP.

## Características do protótipo

- Offline
- Sem permissão de Internet no aplicativo
- Dano em área com baixo cooldown
- Vampirismo/recuperação de HP
- XP e progressão de nível
- Diamantes obtidos durante o jogo
- Sem loja online e sem compras obrigatórias
- Compilação automática de APK pelo GitHub Actions
